# 📋 Pesquisa de Mercado — Validação ProdFind

## Objetivo
Validar se sellers brasileiros de TikTok Shop + Mercado Livre têm dificuldade em achar produtos campeões e se pagariam por uma ferramenta BR que resolva isso.

## Como aplicar
- Enviar via **WhatsApp** para sellers que você conhece ou grupos de vendedores
- Postar em **grupos de TikTok Shop / dropshipping / ML no Telegram**
- Comentar em **posts do Instagram/Nicho** de sellers

---

## Roteiro de abordagem (via WhatsApp)

> "Fala, [nome]! Tudo bem? Sou o Enzo, tô fazendo uma pesquisa com sellers de TikTok Shop e ML pra entender como vocês acham produtos pra vender. São 5 perguntinhas rápidas (2 min). Me ajuda?"

---

## As 5 Perguntas

### 1. Como você encontra produtos para vender hoje?
- [ ] Pesquisa manual no TikTok/ML
- [ ] Grupos de WhatsApp/Telegram
- [ ] Ferramenta paga (qual? ________)
- [ ] Indicação de fornecedor
- [ ] Catálogo de fornecedor (CJ, AliExpress, Shopee)
- [ ] Outro: ________

### 2. Qual sua maior dificuldade na hora de escolher um produto?
- [ ] Saber se o produto realmente está vendendo bem
- [ ] Calcular margem de lucro real (frete, impostos, taxa ML)
- [ ] Encontrar fornecedor confiável
- [ ] Saber se já tem muita concorrência
- [ ] Identificar tendências antes de saturar
- [ ] Outro: ________

### 3. Você já usou ou conhece alguma ferramenta de product research?
- [ ] Sim, uso: ________
  - Quanto paga? R$ ________/mês
  - O que acha? ( ) Ótima ( ) Boa ( ) Regular ( ) Ruim
- [ ] Já tentei mas parei. Por quê? ________
- [ ] Não conheço / nunca usei

### 4. Se existisse uma ferramenta BR que mostrasse:
- ✅ Produtos bombando no TikTok Shop em tempo real
- ✅ Margem de lucro já calculada (fornecedor → ML)
- ✅ Score de potencial com IA
- ✅ Alerta de novos produtos quentes
